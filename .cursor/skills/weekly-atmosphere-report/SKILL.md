# Еженедельный отчёт AtmosphereIQ

## Перед началом

1. **Период отчёта** — если пользователь не указал даты или формулировку периода («с 3 по 9 июля», «неделя 27», «прошлая неделя»), **сначала спроси период**. Не формируй отчёт без него.
2. Собери данные из CRM, файлов, сообщений пользователя или уточни у него цифры. Не выдумывай факты — помечай пробелы как «данные не предоставлены».
3. Используй **только** статусы AtmosphereIQ: `NEW`, `CONFIRMATION`, `INVOICE_SENT`, `PAID`, `INSTALLATION`, `DONE`, `CANCELLED`. Другие статусы не применяй.

## Маппинг статусов по разделам

| Раздел отчёта | Статусы |
|---------------|---------|
| Новые заявки | `NEW` — созданы в периоде |
| Оплаченные заказы | `PAID` — оплата в периоде; кратко: `CONFIRMATION`, `INVOICE_SENT` — в работе, без оплаты |
| Монтажи | `INSTALLATION` — запланированы/идут; `DONE` — завершены в периоде |
| Проблемы | задержки, эскалации, `CANCELLED` в периоде, сбои монтажа, неоплаты |
| Планы на следующую неделю | ожидаемые оплаты, монтажи, follow-up по `CONFIRMATION` / `INVOICE_SENT` |

## Формат ответа

- Тон: **деловой**, от лица команды AtmosphereIQ (мы, наш).
- Объём: **до 300 слов** на весь отчёт.
- Структура **всегда** в этом порядке — заголовки разделов обязательны:

```markdown
# Еженедельный отчёт AtmosphereIQ
**Период:** [даты]

## Новые заявки
[количество, источники, ключевые объекты]

## Оплаченные заказы
[сумма/количество, пакеты, статус передачи в монтаж]

## Монтажи
[запланированные, выполненные, переносы]

## Проблемы
[риски, отмены, блокеры]

## Планы на следующую неделю
[конкретные действия по заказам и клиентам]

## Вопросы для уточнения у команды
- [вопрос 1]
- [вопрос 2]
```

## Раздел «Вопросы для уточнения у команды»

В **самом конце** отчёта выведи маркированный список вопросов, которые руководителю нужно задать команде. Формулируй по пробелам в данных:

- неясные даты монтажа или оплаты;
- заказы без движения в `CONFIRMATION` / `INVOICE_SENT`;
- причины `CANCELLED`;
- перегрузка монтажников;
- клиенты без ответа после КП.

Минимум 3 вопроса, если данных достаточно для их формулировки. Если данных мало — вопросы про недостающие цифры и статусы.

## Чего не делать

- Не менять порядок разделов.
- Не превышать 300 слов (блок «Вопросы для уточнения у команды» можно добавить сверх лимита, если основной текст уже близок к 300).
- Не использовать статусы вне списка из п. 3.
- Не писать канцелярит и рекламные формулировки — только факты и действия.
